# DebiLite
A script that, when run on a nearly empty Debian system, will result in a fully functional system with a desktop, a web browser, and a file manager—one that uses about 200 MB of RAM when no additional software is running. Ideal for low-spec machines or virtual machines.

First, download the Debian netinst from the official website: https://www.debian.org/. Then, write it to a USB drive or use it to create a virtual machine. (If you are installing it on a virtual machine, disable unattended installation) Boot from the USB drive via the boot menu, or start the virtual machine. In the menu that appears, select the “Install” option. From the list, select the appropriate language and press Enter. In the next list, select your geographic location and press Enter. Then select the appropriate keyboard layout from the list and press Enter. Next, wait for the installation to finish. Once it’s done, connect the device to the Internet. If you’re using a virtual machine, make sure the host machine is connected to the Internet! An Internet connection is essential for optimal results. Next, enter a machine name and a domain name. Then, set a password for the root user.
Next, enter the new user’s full name. Then enter the username. Next, set a new password for the new user. Then wait for everything to finish loading and for a new menu to appear. Once the new menu appears, select the appropriate option. The default is the guided installation using the entire disk.
Next, select the disk you want to use from the menu. Make sure you select the correct disk. Then, choose a partitioning scheme. Default: all files on one partition. Next, review the following menu and select “Finalize Partitioning and Save Changes” if everything is correct. Then write the changes to the disks. Wait until a new menu appears. In the menu that appears, configure the package manager. Menus will then appear while the “Select and Install Software” loading screen is displayed. When the “Select Software” menu appears, deselect everything except for the standard system tools. Only those should be selected and installed. Then wait until everything has downloaded and loaded into the system. Configure the Grub boot loader as needed. If there are no other operating systems on the disk, install the boot loader on the primary disk. Select the appropriate disk from the list. Then wait for the installation to complete and restart the computer. Once the system has booted, log in as the root user. The root password is the one you entered during the initial installation. Next, connect to the Internet if you are not using VirtualBox. Then type: apt-get update. Wait for it to finish, then type: apt-get install git. Once it has finished, type `cd /root`, run it, then type `git clone https://github.com/zoardgodor/DebiLite.git`. Wait for it to finish, then type `cd DebiLite`, followed by `chmod +x DebiLite.sh`, and finally `./DebiLite.sh`. Then follow the installer’s instructions. After installation, it’s a good idea to restart the system using the `reboot` command.
